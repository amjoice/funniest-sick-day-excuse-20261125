## What it does

`main.py` (Python 3.13, standard library only) writes one sick-day excuse — a single line, under 200 characters — to `/output/entry.txt`:

> Sorry, can't come in — my smartwatch says I slept 14 hours, ran a marathon, and died twice, and honestly I believe it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
